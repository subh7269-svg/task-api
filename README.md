# Task API

A simple CRUD Task API built with Python and FastAPI.

This project was created as part of the Backend AI Internship assignment.

## Tech Stack

- Python
- FastAPI
- Uvicorn
- Pydantic

## Features

- Create tasks
- Read all tasks
- Read a single task
- Update tasks
- Delete tasks
- Input validation
- 404 error handling
- Swagger UI documentation
